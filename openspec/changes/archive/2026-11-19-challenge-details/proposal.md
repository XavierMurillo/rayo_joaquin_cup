# Event day challenge details

**Checkpoint 1 status** — Approved to implement the layout and [student-facing draft](challenge-copy.md). Exact parameters and scoring details remain pending for a later update today.

## Why

Students already have the official preparation guidelines. They need a place to see the event-day instructions for each challenge so they can adjust their vehicles before competing.

## Scope

- Make each Version III challenge selectable from the existing Challenges section.
- Show its objective, setup, run procedure, allowed adjustments, and evaluation instructions, where confirmed.
- Support an optional organizer-approved reference image or diagram with alternative text and a caption.
- Keep unreleased details clearly marked. Publish exact rules and settings in the edition data as the organizer confirms them.

## Organizer input

For each event, confirm the public challenge name and corresponding module, starting setup, what the vehicle must do, permitted adjustments or interventions, completion and scoring rules, and any constraints or parameters to release. A rough sketch or reference photo is enough to start a visual. Identify any details that should stay unreleased.
