# Challenge winner design

Add a **Select winner** action for the currently selected roulette challenge in Evaluation. Open a labeled team selector and provide Confirm and Cancel controls. Show the recorded winner with a **Change winner** action after confirmation. Use the current edition roster for new selections. If the roster is empty, explain why a winner cannot be recorded.

Persist a selected team ID and name per edition and challenge in browser storage. Keep the confirmed name as an event record if the roster changes later. Use “Winner” on all challenge cards, pop-ups, and terminal bracket columns for consistent terminology. Leave existing draw and bracket state independent of winner selection.
