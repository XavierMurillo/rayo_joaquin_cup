# Random team running order

**Checkpoint 1 status** — Approved for two independent running orders.

Add a roulette to Evaluation with independent running orders for **Challenge 1 — Lead and Follow** and **Challenge 2 — Recognize and React**. The organizer selects a challenge and draws one team at a time from the edition roster. Each undrawn team has the same chance on each spin.

Capture the edition roster independently on the first spin for each challenge. Keep that pool fixed for its draw so roster edits cannot silently change an order in progress. Provide a confirmed reset for the selected challenge that lets the organizer start a new draw with the current roster.

Use each team's selected profile color on the wheel. After a draw is complete, let the organizer save its order to the corresponding challenge card. A later completed save replaces that challenge's previous saved order.

Track brackets for **Challenge 3 — Clear the Arena** and **Challenge 4 — Vehicle Soccer** in a separate ticket. Before planning that ticket, confirm the elimination format, seeding or random pairings, odd-team handling, and whether Vehicle Soccer is one team per side or uses alliances.
